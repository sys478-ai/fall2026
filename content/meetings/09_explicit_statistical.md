## Topic / Focus

What changes when humans stop writing every rule? We start with spam: an IF/ELSE list versus many labeled examples that adjust a model. Explicit programming is rules + data → output. Machine learning is data + an objective → a learned model → output.

A short history (symbolic AI, expert systems, statistical learning, deep learning, foundation models) shows overlapping traditions, not a clean sequence. Sept. 17 asks what “learn from examples” actually means: training data, labels, prediction, error, and parameter adjustment.

## Guiding Questions

- Where does explicit programming break down, and what does a statistical approach do instead?
- If humans are no longer writing every rule, where does human judgment move?
- How do representation, procedure, learning, categories, and values still shape a learned system?

## In This Class

In this meeting, we will:

- contrast spam rules with labeled examples, then name where explicit procedures fail: too many exceptions, tacit judgments, perception
- walk a short, overlapping AI history from hand-coded rules to foundation models
